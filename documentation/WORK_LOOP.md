# WORK_LOOP.md — The Daily Autonomous Loop

Whenever this project is resumed (new session, scheduled check-in, or continuation), execute:

1. Read `COMPANY.md`, `DECISIONS.md`, `STRATEGY.md`, `AFFILIATES.md`, `METRICS.md`, `BACKLOG.md`, `ACCESS_NEEDED.md`, `EXPERIMENTS.md`.
2. Review current metrics in `METRICS.md` — what changed since last session (traffic, clicks, revenue)?
3. Identify the current bottleneck (usually named explicitly in `BACKLOG.md` top item or `ACCESS_NEEDED.md`).
4. Pick the single highest expected-value task using the prioritization formula:
   `(Potential Revenue × P(success) × Scalability × Recurring Value) / (Capital × Human Effort × Time-to-Revenue × Complexity)`
5. Execute it fully (don't half-finish).
6. Update or create tracking so the result is measurable (UTM link, experiment entry, KPI row).
7. Update `METRICS.md`, `EXPERIMENTS.md`, `BACKLOG.md`, `DECISIONS.md` as applicable.
8. Pick the next highest-value task and continue — do not stop after one small task while more high-value, non-blocked work exists.
9. Only stop to ask the human when genuinely blocked (credentials, payment, legal, irreversible decision) — bundle asks into `ACCESS_NEEDED.md` rather than interrupting repeatedly.

## Weekly CEO review
Produce `reports/weekly-YYYY-MM-DD.md` covering: executive summary, revenue, growth, winners, losers, learnings, opportunities, risks, next actions — per `COMPANY.md`/founding brief Section 26. Trigger this whenever ~7 days have elapsed since the last report, or when asked.
